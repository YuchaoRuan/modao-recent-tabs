# 墨刀企业版「最近画布」浏览器扩展

与**桌面客户端**功能一致的浏览器版本：在墨刀企业版（内网 `http://10.83.117.101:9080`）的**设计文件页**顶部，以标签栏展示你最近打开的画布（设计文件内的 screen），支持快速切换、单标签关闭、关闭其他、画布列表下拉、固定/浮动显示。

> 本目录根即为可直接「加载已解压的扩展程序」的扩展包（含 `manifest.json`）。桌面的 `app.asar` 补丁版在 `desktop/` 与 `release/` 中，互不影响。

## 与桌面客户端的关系
- 功能与交互逻辑完全一致（同一套 `tabbar.js` 组件 + 同一套画布检测逻辑）。
- 数据源同样是同源 `localStorage['screen-history-onLeave-project-<cid>']` 与左侧画布栏 DOM，不依赖 modao.cc。
- 区别：浏览器扩展用内容脚本注入，无需改客户端 `app.asar`，团队成员用 Chrome/Edge 即可安装。

## 功能清单
- 顶部标签栏展示**当前设计文件**内最近打开的画布，按最近时间排序
- 进入文件时默认打开的画布、以及你点过的画布，都会自动加入并置顶
- 点标签 → 切换到对应画布（模拟点击左侧画布项，URL 不变），并在左侧「画布」列表里**滚动定位到它、将其高亮为左栏选中态**（v1.0.18 起；若你随后手动滚动列表，插件不会再抢回滚动位置）；点 × → 关闭该标签（仅本地）
- 右侧「画布 N」→ 点击展开画布列表下拉，点任意项切换
- 右侧「关闭其他」→ 只保留当前画布标签，关闭其余
- 右侧「图钉」→ 切换固定显示 / 浮动显示（浮动时标签栏自动隐藏，鼠标移到**窗口最顶部 4px** 滑出，离开自动收起）

> 所有关闭操作只移除本地标签，**不修改墨刀里的画布数据**。

## 安装（开发者模式加载）
1. 浏览器打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 右上角开启**「开发者模式」**。
3. 点**「加载已解压的扩展程序」**，选择本目录（`modao-recent-tabs/`）。
4. 打开内网墨刀，进入任一**设计文件**页，窗口顶部即出现「最近画布」标签栏。

## 服务器地址不是默认的怎么办
- 扩展默认对 `http://10.83.117.101:9080/*` 自动注入。
- 若你的内网地址不同：
  - 在扩展「设置」页填写**墨刀服务器地址**并保存（扩展图标 → 右键 → 选项），该地址下的页面会自动注入；
  - 或在任意墨刀标签页点**工具栏扩展图标**手动注入（覆盖 manifest 未匹配的自定义地址）。

## 设置页
- 扩展图标 → 右键 → **选项**（或首次安装自动打开）。
- 可配置：墨刀服务器地址。
- 「清除已关闭标签」：恢复此前被关闭的画布（需在墨刀设计文件页处于打开状态，会向内容脚本发消息）。

## 真机定位失败（点标签提示「未找到画布」）排查两步

> 教训（2026-09-16）：一次「真机复验仍未解决」其实是**扩展没有重新加载** —— 页面里跑的
> 还是上一版的代码。所以排查第一步永远是**核对版本**；版本不对，后面所有测试结论都不成立。

**第一步 核对当前真正加载的版本**（在设计页 Console 执行）：

```js
document.querySelector('#md-recent-tabs-root').getAttribute('data-md-version')
```

它必须等于仓库 `VERSION` 的当前值。若不是：

1. `chrome://extensions` → 找到本扩展 → 点**「重新加载」**（卡片上的刷新图标）；
2. 进该卡片**「详情」**，确认**来源路径就是本仓库根目录**（含 `manifest.json` 的那一层，
   即 `modao-recent-tabs/`）。⚠ 本机存在其它 `modao-recent-tabs` 副本时，
   加载错目录会导致「怎么改都不生效」；
3. 回到设计页 **Ctrl+Shift+R** 强刷，再跑一次上面这行确认。

**第一步（补充）构建指纹**：版本号在「未获确认」期间是**冻结**的（改动纪律第 10 条），
所以版本号相同**不代表**代码相同。用构建指纹区分：

```js
document.querySelector('#md-recent-tabs-root').getAttribute('data-md-build')
```

- `locate-robust.3`（= **本轮最终包**：定位加固第 2 轮 + 末位结构展开 + 只读探针 + 自产点击护栏）；
  上一档 `locate-robust.2`（只有 0016/0017/0018，**没有**末位兜底、探针与护栏）；
- 返回 `null` / `undefined` ⇒ 页面上跑的还是**没有构建指纹的旧代码**（重新加载扩展 + 强刷）。
- ⚠ `locate-robust.2` 与 `.3` 的差别只在一处：**当「搜索两条路 + aria 展开」全都够不着时，
  `.3` 还会按结构把折叠分组点开**。若你的场景正好落在这个盲区，`.2` 会失败、`.3` 才有救，
  所以复验前务必先确认这一行返回的是 `.3`。

**第一步（补充）安装包**：真机是**另一台机器**（内网从开发机不可达），改仓库 ≠ 改真机。
拿到新包后：解压覆盖真机扩展目录 → `chrome://extensions` 重新加载 → 设计页 **Ctrl+Shift+R**
→ 先核对上面两个属性，**再**复验问题。

**第二步：仅当版本正确、问题仍复现时**，再跑取证探针。

**先用内置一行探针（推荐，`locate-robust.3` 起提供）** —— 不必先让它失败，
**加壳前**就能拿到折叠态样本（这正是本项目反复卡住的那块证据）：

```js
copy(JSON.stringify(__mdRtProbe(), null, 1))
```

- 不带参数 = 对标签栏里每条最近画布各出一份；也可 `__mdRtProbe('<cid>')` 只查一条；
- 它**只读**：不点任何行、不切换画布、不弹提示（有用例 `H6` 锁定这一性质）。

**再跑完整探针脚本**（老版也适用）：

- 打开 `scripts/probe-locate-real.min.js`（**单行版**，整份 Ctrl+A / Ctrl+C 复制），
  在设计页 Console 粘贴回车；
- 输出会 `console.log` 并 `copy()` 到剪贴板，整段回贴即可；
- 三个决定性数字：
  - `cidHitTotal` —— 标签里存的 id，在文档中还有几个元素带它（`0` = 该 id 已不在 DOM）；
  - `nameRowsBefore` —— **不看 id**、按名字能命中的行（含祖先链，看它被谁包住）；
  - `nameRowsAfterSearch` —— 把名字写进墨刀自己的搜索框后，行是否出现、
    出现时的 `cid` 是否与标签里存的 id 一致。

> 为什么另做单行版：多行脚本经聊天/剪贴板复制会被折断（曾出现一行拼接残片，
> 直接 `Uncaught SyntaxError`，脚本根本没执行，白跑一轮）。
> 可读注释版见 `scripts/probe-locate-real.js`。

## 定位加固第 2 轮（2026-09-17）改了什么

针对「曾经打开的画布仍在左栏画布列表中，只是被**收缩折叠**不可见（或因滚动不在可见区域），
点它的标签却提示『未找到画布』」，本轮补了三个**结构性**缺陷 —— 前三轮修的都是**判据类**
问题（容器锚点识别 / 黑名单误判 / 扫描步长放大），改动都落在「候选接受规则」与「扫描步长」上；
本轮这三个不在同一条路径上，所以按前几轮的思路继续改是收敛不了的：

1. **折叠分组现在会被主动展开（BUG-0016，根因）**：以前唯一的展开入口只在
   「**已经找到那一行之后**」才会执行，而折叠恰恰让行找不到 ⇒ 展开步骤永远走不到 ——
   「要展开得先找到行，要找到行得先展开」的死循环。现在改成**不依赖目标行是否存在**，
   直接在「画布」列范围内展开所有处于折叠态的开关（只认标准 `aria-expanded="false"`，
   **绝不越出画布列容器**，**不新增任何猜测式点击**）。
2. **搜索框探测不再因 UI 漂移而整体失效（BUG-0017）**：以前只要搜索框的文案/位置与代码假定
   不一致（`placeholder` 不含「搜索/查找/检索」、或不在视口顶部 300px 内），
   「清空过滤 / 按名检索 / 展开折叠」三条能力会被**一起跳过**，只剩滚动扫描（对折叠行无效）。
   现在按「**结构优先**（画布列容器内的输入框）→ 文案 → 兼容」四级探测，命中级别写进诊断
   （`searchBoxSource`）；检索词也改为**阶梯**（全名 → 前 8 字 → 前 4 字，命中即停）。
3. **图层树同名容器不再被无条件拒绝（BUG-0018）**：`.layer-sortable-list` 与页面列的
   `.canvas-sortable-list` 属**同一套列表组件**，同样会被「画布」列在存在分组 / 需要滚动时
   复用；以前它落在图层树黑名单里被一律拒绝 ⇒ 行即使在 DOM 里也永远查不到。
   现在只有**面板级容器**（`#mb-enabled-layer-list` / `#layer-scroll-list` / `#mb-state-list` /
   `#interaction-tree-*` 等）才无条件拒绝，**共享组件的类名**仅在「不在画布列内」时拒绝；
   防误点仍由「真画布行不带 `layer-item`」这条**与容器无关**的判据兜底。
4. **末位兜底：按「结构」展开折叠分组（`locate-robust.3`）**。真机实测画布列里
   **没有** `aria-expanded="false"`（`collapsedToggleCount = 0`），所以第 1 条在真机上
   很可能是空操作；若搜索框那两条路也够不着，就一条路都不剩 —— 那是**必然失败**的死角。
   补的判据是**结构**、不是猜测：在「画布」列内，一个**自身可见**的行却包着**不可见**的
   `ul` 列表容器（叶子画布行不会含列表容器）。它**只在「本来就要报失败」的分支里执行**
   （正常流程永不触发）、只在画布列锚点内寻找、只点行的内层行项、**不点目标行本身**、
   同一节点只点一次。

**若仍复现**：Console 会打印结构化诊断对象，重点看这几个字段 ——
`build`（跑的是哪一份代码，必须是 `locate-robust.3`）、`cidHitTotal`（该 id 在文档里还有几个节点；
`0` = 已被移出 DOM）、`rowHitTotal`（过了判据的有几条；为 0 而 `cidHitTotal > 0` ⇒ 行在、被**判据拒绝**）、
`searchBoxSource`（搜索框是怎么找到的：`anchor` / `placeholder` / `legacy` / `none`）、
`panelCollapsedToggles`（画布列内 aria 折叠开关数）、`panelStructuralToggles`（画布列内
**按结构**认出的折叠分组行数）。判读组合：

| 观测 | 含义 | 下一步 |
|---|---|---|
| `cidHitTotal = 0` | 该 id 在整份文档里一个节点都没有 | 行已被移出 DOM → 它不在左栏，或还没加载 |
| `cidHitTotal > 0` 且 `rowHitTotal = 0` | 行在，但全被判据拒绝 | 又有新的类名 / 容器形态没覆盖（看 `reason`） |
| 两个折叠计数**都为 0** | 画布列里既无 aria 折叠、也无结构可辨的折叠容器 | **折叠解释不成立** → 回到上面两行 |
| `panelStructuralToggles > 0` 但仍失败 | 找得到折叠开关、点了却没展开 | 说明展开交互**不是 `click`** → 需要录一次真机点击事件的探针 |

## 自测清单
- [ ] 加载扩展后进入设计文件页，顶部出现「最近画布」标签栏
- [ ] 依次点击左侧多个画布，标签栏按最近顺序出现对应标签
- [ ] 点标签可切回对应画布（画布内容变化，地址栏 URL 不变）
- [ ] 点 × 关闭某标签，该标签消失；刷新页面后该画布不再出现（本地记录生效）
- [ ] 点「关闭其他」，仅保留当前画布标签
- [ ] 点「画布 N」徽标，下拉列出所有画布，点任一项可切换
- [ ] 点「图钉」切换为浮动：标签栏隐藏，鼠标移到窗口最顶部 4px 滑出，离开收起
- [ ] 浮动模式下把鼠标移到墨刀顶部工具栏按钮上：标签栏**不弹出**，且按钮可正常点击
- [ ] 进入文件时默认打开的画布已出现在标签栏
- [ ] 左侧「画布」列里**被折叠分组收起来**的画布，点它的标签能定位到那一行并把画布切过去
- [ ] 左侧「画布」列里的画布**滚出可见区域**（不在视野内）时，点它的标签同样能定位并切换
- [ ] 上述两种情况定位后，左栏该行**停在可视区内**（不会「刷新一下回到列表顶部」）
- [ ] 上述操作**不会**点到下部「页面」列 / 「图层」列里的同名节点
- [ ] Console 里 `document.querySelector('#md-recent-tabs-root').getAttribute('data-md-build')`
      返回 `locate-robust.3`（否则跑的不是本轮修复版）
- [ ] 把某个分组**手动折叠**起来，再点其中画布的标签：能自动展开分组并把画布切过去
- [ ] 上面的自动展开**不会**在标签栏里多出一个「分组名」标签（展开动作只该展开，不该建标签）
- [ ] Console 里 `__mdRtProbe()` 返回数组且 `panelStructuralToggles ≥ 1`（探针认得出折叠分组）

## 目录结构（本扩展）
```
modao-recent-tabs/            # 本目录即可作为「已解压的扩展程序」加载
├── manifest.json             # MV3 清单（content_scripts / action / options_page）
├── content.js                # 内容脚本：画布数据 + 交互逻辑（移植自桌面端）
├── tabbar.js                 # 标签栏 UI 组件（RecentTabsBar，桌面/扩展共用）
├── tabbar.css                # 标签栏样式（含固定/浮动模式）
├── background.js             # Service Worker：安装引导 + 工具栏手动注入
├── options.html              # 设置页
├── options.js                # 设置页逻辑（服务器地址 / 清除已关闭标签）
├── README.browser.md         # 本说明
├── release/
│   └── modao-recent-tabs-browser.zip   # 可分发的扩展包（仅含上述扩展文件）
├── desktop/                  # 桌面客户端 app.asar 补丁版（与本扩展独立）
└── sniffer-canvas-*.js       # 桌面端排障工具（可选）
```

## 说明
- 扩展只在**设计文件页**（`/proto/design/<cid>`）挂载标签栏；`/workspace` 等页面不显示。
- 若墨刀前端为 SPA 且在同一标签页内跨设计文件跳转（地址栏 pathname 变化），标签栏会随新文件重新加载画布列表。
- 自动注入的地址在 `manifest.json` 的 `content_scripts.matches` 中；自定义地址用设置页或工具栏图标处理。
