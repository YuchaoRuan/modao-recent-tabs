# 墨刀企业版「最近画布」浏览器扩展

与**桌面客户端**功能一致的浏览器版本：在墨刀企业版（内网 `http://10.83.117.101:9080`）的**设计文件页**顶部，以标签栏展示你最近打开的画布（设计文件内的 screen），支持快速切换、单标签关闭、关闭其他、画布列表下拉、固定/浮动显示。

> 本目录根即为可直接「加载已解压的扩展程序」的扩展包（含 `manifest.json`）。桌面的 `app.asar` 补丁版在 `desktop/` 与 `release/` 中，互不影响。

## 与桌面客户端的关系
- 功能与交互逻辑完全一致（同一套 `tabbar.js` 组件 + 同一套画布检测逻辑）。
- 数据源同样是同源 `localStorage['screen-history-onLeave-project-<cid>']` 与左侧画布栏 DOM，不依赖 modao.cc。
- 区别：浏览器扩展用内容脚本注入，无需改客户端 `app.asar`，团队成员用 Chrome/Edge 即可安装。

## 功能清单
- 顶部标签栏展示**当前设计文件**内最近打开的画布，按最近时间排序
- 进入文件时默认打开的画布、以及你点过的画布，都会自动加入并置顶
- 点标签 → 切换到对应画布（模拟点击左侧画布项，URL 不变）；点 × → 关闭该标签（仅本地）
- 右侧「画布 N」→ 点击展开画布列表下拉，点任意项切换
- 右侧「关闭其他」→ 只保留当前画布标签，关闭其余
- 右侧「图钉」→ 切换固定显示 / 浮动显示（浮动时标签栏自动隐藏，鼠标移到窗口顶部滑出，离开自动收起）

> 所有关闭操作只移除本地标签，**不修改墨刀里的画布数据**。

## 安装（开发者模式加载）
1. 浏览器打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 右上角开启**「开发者模式」**。
3. 点**「加载已解压的扩展程序」**，选择本目录（`modao-recent-tabs/`）。
4. 打开内网墨刀，进入任一**设计文件**页，窗口顶部即出现「最近画布」标签栏。

## 服务器地址不是默认的怎么办
- 扩展默认对 `http://10.83.117.101:9080/*` 自动注入。
- 若你的内网地址不同：
  - 在扩展「设置」页填写**墨刀服务器地址**并保存（扩展图标 → 右键 → 选项），该地址下的页面会自动注入；
  - 或在任意墨刀标签页点**工具栏扩展图标**手动注入（覆盖 manifest 未匹配的自定义地址）。

## 设置页
- 扩展图标 → 右键 → **选项**（或首次安装自动打开）。
- 可配置：墨刀服务器地址。
- 「清除已关闭标签」：恢复此前被关闭的画布（需在墨刀设计文件页处于打开状态，会向内容脚本发消息）。

## 自测清单
- [ ] 加载扩展后进入设计文件页，顶部出现「最近画布」标签栏
- [ ] 依次点击左侧多个画布，标签栏按最近顺序出现对应标签
- [ ] 点标签可切回对应画布（画布内容变化，地址栏 URL 不变）
- [ ] 点 × 关闭某标签，该标签消失；刷新页面后该画布不再出现（本地记录生效）
- [ ] 点「关闭其他」，仅保留当前画布标签
- [ ] 点「画布 N」徽标，下拉列出所有画布，点任一项可切换
- [ ] 点「图钉」切换为浮动：标签栏隐藏，鼠标移到窗口顶部滑出，离开收起
- [ ] 进入文件时默认打开的画布已出现在标签栏

## 目录结构（本扩展）
```
modao-recent-tabs/            # 本目录即可作为「已解压的扩展程序」加载
├── manifest.json             # MV3 清单（content_scripts / action / options_page）
├── content.js                # 内容脚本：画布数据 + 交互逻辑（移植自桌面端）
├── tabbar.js                 # 标签栏 UI 组件（RecentTabsBar，桌面/扩展共用）
├── tabbar.css                # 标签栏样式（含固定/浮动模式）
├── background.js             # Service Worker：安装引导 + 工具栏手动注入
├── options.html              # 设置页
├── options.js                # 设置页逻辑（服务器地址 / 清除已关闭标签）
├── README.browser.md         # 本说明
├── release/
│   └── modao-recent-tabs-browser.zip   # 可分发的扩展包（仅含上述扩展文件）
├── desktop/                  # 桌面客户端 app.asar 补丁版（与本扩展独立）
└── sniffer-canvas-*.js       # 桌面端排障工具（可选）
```

## 说明
- 扩展只在**设计文件页**（`/proto/design/<cid>`）挂载标签栏；`/workspace` 等页面不显示。
- 若墨刀前端为 SPA 且在同一标签页内跨设计文件跳转（地址栏 pathname 变化），标签栏会随新文件重新加载画布列表。
- 自动注入的地址在 `manifest.json` 的 `content_scripts.matches` 中；自定义地址用设置页或工具栏图标处理。
